## Задача

1. Ознакомиться [с требованиями к сервису "Бэкенд кредитной карты"](https://confluence.korona.net/spaces/SHIFTLAB/pages/1377580584/Тестирование+требований.+Требования+к+сервису+Бэкенд+кредитной+карты+-+Python+Backend+QA+2026-1)

2. **Задание 1:** Отметить примеры требований, которые относятся к следующим видам:
   - Бизнес-требование
   - Бизнес-правило
   - Пользовательские требования
   - Атрибуты качества
   - Требования к функциям системы
   - Системные требования
   - Внешние системы и интерфейсы
   - Ограничения

3. **Задание 2:** Оценить требования по критериям качества:
   - Полнота
   - Однозначность
   - Корректность
   - Непротиворечивость
   - Необходимость
   - Осуществимость
   - Проверяемость

   Выделить требования, которые не соответствуют критериям качества, обосновать выбор и сформулировать уточняющие вопросы автору требований.
